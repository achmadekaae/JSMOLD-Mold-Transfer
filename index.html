Konfigurasi Firebase belum diisi

Halaman ini butuh database Firebase gratis milikmu sendiri supaya bisa dipakai bersama 4 anggota. Langkah singkat:

  1. Buka console.firebase.google.com, buat project baru (gratis).
  2. Menu Build → Firestore Database → Create database → mode production.
  3. Menu Build → Authentication → Sign-in method → aktifkan Anonymous.
  4. Menu Project settings (ikon gerigi) → scroll ke "Your apps" → tambah Web app (ikon </>) → salin objek firebaseConfig.
  5. Buka file HTML ini di editor teks, cari tulisan LANGKAH 1, tempel konfigurasinya di sana, simpan.
  6. Muat ulang halaman ini.
